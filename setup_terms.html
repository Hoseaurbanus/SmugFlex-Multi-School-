Setup Term Structure

Create independent term structure for all academic years

Important Information

This creates the structure for all three terms. Each term will have its own independent assignments - no copying between terms. You'll need to assign teachers separately for each term.

What this script does:

  • • Creates subject registration structure for all three terms
  • • Sets up available terms in school settings
  • • Prepares independent assignment structure for each term
  • • Does NOT copy assignments between terms
  • • Works with your live domain: gracelandroyalacademy.com

After running this script:

  • • Go to Admin Dashboard → Term & Session Settings
  • • Set your desired current term (First/Second/Third Term)
  • • For each term, manually assign:
  •  - Class teachers (Admin → Teacher Assignments)
  •  - Subject teachers (Admin → Subject Assignments)
  • • Each term maintains completely independent assignments

Benefits:

  • • All three terms available for each academic year
  • • Independent teacher assignments per term
  • • No conflicts between terms
  • • Proper term-based data management
  • • Users, classes, and subjects remain constant across terms

Domain: gracelandroyalacademy.com.ng | Note: This is a one-time setup. After running, assign teachers manually for each term.
